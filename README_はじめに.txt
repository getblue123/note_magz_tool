W｜note マガジン追加サポート V10.0.0
=================================

【概要】
note.com の公開記事を取得して CSV リストを作成し、選んだ記事を指定のマガジンへ順番に追加するための非公式 Chrome 拡張機能です。
どの note アカウントでも、本人がログインした通常の Chrome から利用できます。
個別アカウントに固定されていません。

【インストール】
1. ZIP ファイルを任意の場所へ解凍します。
2. Chrome で chrome://extensions/ を開きます。
3. 画面右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」で manifest.json のあるフォルダーを指定します。
5. Chrome の拡張機能アイコンから「W｜note マガジン追加サポート」を開きます。

※以前のバージョンの進捗を引き継ぐには、旧バージョンで読み込んだ同じフォルダーの内容を更新してから、拡張機能の「更新」をクリックしてください。
  別フォルダーに新規インストールすると、Chrome に別の拡張機能として扱われ、旧進捗は自動で移りません。

【使い方：CSV を自動作成する場合】
1. Chrome で note.com にログインします（認証情報を拡張機能に渡す必要はありません）。
2. 拡張機能の「2. 公開記事を取得して CSV を作成」に note ID またはプロフィールURLを入力します。
3. 「記事一覧を取得」を押すと、通常の Chrome タブで公開プロフィールの /all ページを開きます。
   新しく開いたタブを閉じないでください。自動スクロールに加え、「もっとみる」を押して後続記事も順番に読み取ります。
4. 拡張機能を開き直し、「取得件数」を確認します。途中で読込失敗・上限到達した場合は「未完了」と表示します。
5. CSV の「初期選択」は通常「空欄（選びたい記事に Y）」のままにします。
   「記事リスト CSV を保存」を押すと note_articles_ユーザーID.csv をダウンロードできます。
6. Excel 等で CSV を開き、追加したい行の「追加(Y)」列に Y を入力して UTF-8 CSV として保存します。
   最初から全部追加する場合は、CSV 生成前に「すべて Y」を選ぶこともできます。
7. 拡張機能の「3. 対象記事の CSV／URL リストを読み込む」で編集した CSV を選びます。
8. リスト順か「話数が小さい順」を選び、正式なマガジン名を入力します。
9. 「まず3件をテスト」から始め、マガジンで結果を確認してから残りを一括追加します。

【使い方：手元の CSV／TXT を直接利用する場合】
1. 「3. 対象記事の CSV／URL リストを読み込む」から既存のファイルを指定します。
2. 処理順序とマガジンを選択し、「まず3件をテスト」から操作します。
3. 不確実な状態では停止し、「処理結果を CSV で保存」で記録を確認できます。

【自動取得の対象と制限】
- 公開プロフィールの「記事一覧」に表示されるリンクのみが対象です。下書きや非公開記事は収集しません。
- クリエイターページで非表示にした公開記事は、一覧から収集できないことがあります。
- note の表示方式やスクロール読み込みが変わった場合、一部の記事を取りこぼすことがあります。
- 取得した件数を実際の公開記事数と照合してください。足りない場合は不足分のURLを手動でCSVに追加してください。
- 500件を上限とします。取得処理は公開ページを読むだけで記事を変更しません。
- 「もっとみる」を押しても新しい記事が増えない場合は未完了として警告し、取得済みのCSVだけを保存できます。
- 収集が「完了」と表示されても、非表示の記事などは対象外です。必要に応じて公開記事数と照合してください。
- 特定のアカウント名や連載作品名への依存はありません。

【CSV フォーマット】
「記事URL」は必須、「記事タイトル」は話数順で使用、「追加(Y)」は選択用です。
例：
追加(Y),記事タイトル,記事URL
Y,第1話 はじまり,https://note.com/example_id/n/n123456789abc
,第2話 つづき,https://note.com/example_id/n/n23456789abcd
Y,第3話 旅立ち,https://note.com/example_id/n/n3456789abcde

上記 URL は説明用の架空サンプルです。実際の note 記事の URL に置き換えてください。
「追加(Y)」列がない場合は、CSV 内の全記事が対象です。
以前の中国語版に含まれる「加入(Y)」「文章標題」「文章網址」も読み込めます。
TXT は、1行に1記事の完全な URL を記入してください。空行と # で始まる行は無視されます。
一度に処理するリストは最大500件、同一投稿者のURLのみです。

【話数の判定】
第1話、第2章、3話、Episode 4、Chapter 5、作品名』6. などの表記から番号を抽出します。
「前編」「後編」があれば同じ話数内で順序を調整します。
判定できないタイトルは末尾へ配置し、元のCSV内の相対順を維持します。
追加する順序と note マガジンの表示順は必ずしも一致しません。
必要ならマガジン側の「並び替え」で表示順を調整してください。

【動作の注意】
- 個人のパスワード、Cookie、非公開 API へはアクセスしません。
- note.com のUIが変更された場合は認識に失敗することがあります。
- 記事の「本＋」ボタンが特定できない場合は画面上で手動指定を求めます。
- 追加後に「追加済」を確認できない場合は、二重追加を避けるため停止します。
- 対象マガジンの同名判定ができない場合にも停止します。
- ページ操作は note.com 上でのみ実行されます。
- note 公式・運営会社とは無関係の非公式ツールです。Chrome Web Store に公開する場合はポリシーや必要な説明・プライバシー情報を別途確認してください。

【更新の際の進捗】
旧版と同じ拡張機能として更新すると、対応するデータを可能な範囲で引き継ぎます。
実行履歴はブラウザー内のローカルストレージに保存されます。
旧版の保留・確認待ちの記録は、重複追加を防ぐため結果CSVで手動確認してください。
