# W｜note マガジン追加サポート

<img src="icons/w128.png" alt="W" width="80">

**noteの記事をまとめてマガジンに追加する、無料の非公式Chrome拡張機能です。**

記事一覧の取得、CSVでの選択、マガジンへの追加をサポートします。

## インストール

1. **Code → Download ZIP** からダウンロードして解凍
2. Chromeで `chrome://extensions` を開く
3. **デベロッパーモード** をオン
4. **パッケージ化されていない拡張機能を読み込む** から、`manifest.json` のあるフォルダーを選択

## 使い方

1. Chromeでnoteにログインし、拡張機能に **note ID** を入力して記事一覧を取得
2. CSVを保存し、追加したい記事の **追加(Y)** 列に `Y` を入力して保存
3. CSVを読み込み、**マガジン名**を入力して **まず3件をテスト** → 問題なければ残りを追加

※初回は記事の **「本＋」** ボタンの位置確認が必要な場合があります。

## 注意

- **note公式のツールではありません。** 仕様変更などで動作しない場合があります。
- 取得対象は公開プロフィールに表示される記事です。取得件数をご確認ください。
- **必ず3件で試してから**一括実行してください。
- マガジンへの追加順と表示順は異なる場合があります。
