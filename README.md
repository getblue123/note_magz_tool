# W｜note マガジン追加サポート

<img src="icons/w128.png" alt="W アイコン" width="96">

**noteの記事をまとめてマガジンに追加する、無料・非公式のChrome拡張機能です。**

公開記事の一覧取得からCSVの作成、追加対象の選択、マガジンへの追加までをサポートします。個人制作のツールであり、note公式とは関係ありません。

> **はじめて使う方へ：** まず3記事だけテストし、正しいマガジンに追加されたことを必ず確認してください。

## ⬇️ ダウンロード・インストール

現在はChromeウェブストアでの配布は行っていません。GitHubから手動でインストールしてください。

1. このページ右上の緑色の **Code** → **Download ZIP** からダウンロードします。
2. ZIPを任意の場所へ**解凍**します。
3. Google Chromeのアドレス欄に `chrome://extensions` と入力します。
4. 右上の **デベロッパー モード** をオンにします。
5. **パッケージ化されていない拡張機能を読み込む** をクリックします。
6. 解凍したフォルダーのうち、`manifest.json` が入っているフォルダーを選択します。
7. Chromeの拡張機能メニューから **W｜note マガジン追加サポート** を開きます。

※フォルダーを移動・削除すると拡張機能が動かなくなる場合があります。解凍先はそのまま残してください。

## 📖 使い方

1. 普段使っているChromeで **[note.com](https://note.com/)** にログインします。
2. 拡張機能で自分の **note ID** またはプロフィールURLを入力し、**記事一覧を取得** を押します。
3. 「もっとみる」を含む公開記事一覧の取得が終わったら、**記事リスト CSV を保存** を押します。
4. CSVをExcelなどで開き、追加したい記事の **追加(Y)** 列に `Y` を入力して、**UTF-8のCSV形式** で保存します。
5. 編集したCSVを拡張機能に読み込みます。
6. 必要に応じて**リスト順**または**話数が小さい順**を選択し、追加先の**正式なマガジン名**を入力します。
7. **まず3件をテスト** を実行し、noteのマガジンで結果を確認します。問題がなければ **残りを一括追加** を実行します。

### 初回の「本＋」ボタン確認

画面によっては「記事を追加」ボタンの場所を確認する案内が表示されます。その場合は、記事の「スキ♡」「コメント」の近くにある **本に＋が付いたアイコン** を指定してください。

### CSVを自分で用意する場合

既存のCSVまたはURLを1行ずつ並べたTXTも利用できます。CSVの形式例：

```csv
追加(Y),記事タイトル,記事URL
Y,第1話 はじまり,https://note.com/example_id/n/n123456789abc
,第2話 つづき,https://note.com/example_id/n/n23456789abcd
```

上記URLは架空のサンプルです。

## 主な機能

- 公開記事一覧を取得（「もっとみる」に対応）
- 記事タイトルとURLをCSVに保存
- CSVで追加対象の選択
- 連載作品の話数順での処理
- 3件のテスト実行、残りの一括追加、停止、処理結果のCSV保存

## ⚠️ 注意事項

- 本ツールは**note非公式**です。noteの画面仕様が変わると動作しない可能性があります。
- 下書き・非公開記事や、プロフィール上で非表示になっている記事は自動取得できない場合があります。取得件数を確認してください。
- 記事一覧の自動取得は最大500件、追加対象も1回あたり最大500件です。
- マガジンへの**追加順と表示順は必ずしも一致しません**。必要に応じてnote側で並び替えてください。
- 誤操作や二重追加を防ぐため、判断できない場面では処理を停止する場合があります。
- **最初は必ず3件でテスト**し、結果を確認してから続行してください。

詳しい仕様・制限・更新方法は [README_はじめに.txt](README_%E3%81%AF%E3%81%98%E3%82%81%E3%81%AB.txt) をご確認ください。
